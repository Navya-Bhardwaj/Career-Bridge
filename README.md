# CareerBridge 🚀

A full-stack job portal designed to connect job seekers with recruiters through a secure and scalable platform.

> **Status:** 🚧 Under Development

# Tech Stack

### Backend
- Java 21
- Spring Boot 3
- Spring Data JPA
- Spring Security
- Hibernate
- MySQL
- Maven
- Lombok

### Tools
- IntelliJ IDEA
- Postman
- Git & GitHub
